# 📡 MeluCBT - 정보통신기사 필기 기출문제 개인 CBT

> **2016년~2023년 총 23개 회차, 2,300개 기출문제**와 **424개의 고해상도 회로도/도표/수식 이미지**, 그리고 **전 문항 핵심 공학 해설**을 완벽하게 탑재한 개인 맞춤형 웹 CBT 학습 사이트입니다.
> 
> 로그인 및 데이터베이스 없이 순수 정적 파일(HTML5 + Vanilla CSS + Vanilla JS)로 동작하며, **GitHub Pages** 등을 통해 무료로 영구 배포할 수 있습니다. PC와 모바일 브라우저 모두에 완벽 대응하는 반응형 디자인 및 PWA(홈 화면에 추가)를 지원합니다.

---

## ✨ 핵심 기능

1. **⚡ 스마트 랜덤 연습**
   - **과목별 / 출제 연도별** 다중 필터링 지원 (최근 5년 우선 선택 가능)
   - 풀이 문항 수 선택 (10 / 20 / 30 / 50 / 전체)
   - 문항 선택 즉시 정답/오답 판정 및 자동 채점
   - 키보드 단축키 지원 (`1`~`4`: 보기 선택, `←`/`→`: 문제 이동, `Enter`: 정답 토글, `B`: 북마크)

2. **⏱️ 실전 모의고사 (100제 / 150분)**
   - 실제 자격검정 시험과 동일한 100문항 5개 과목 구성
   - 150분 카운트다운 타이머 & 실시간 **OMR 답안지 마킹 카드** (미응시 문항 수 표시, 문항 바로가기)
   - 시험 종료 시 **합격/불합격 판정** (평균 60점 이상 & 전 과목 40점 이상 과락 방지)
   - 과목별 점수 분석 리포트 제공

3. **📕 오답노트 자동 누적 & 집중 복습**
   - 연습 모드 또는 실전 모의고사에서 틀린 문제를 브라우저 `localStorage`에 자동 보관
   - 오답만 따로 모아 재시험을 치를 수 있으며, 해결 시 오답노트에서 자동/수동 제거 가능
   - 기기 변경을 위한 **데이터 백업(JSON 다운로드) 및 복원** 기능 제공

4. **📅 23개 기출 회차별 정주행**
   - 2023년 최신 회차부터 2016년 회차까지 실제 시험 순서(1~100번)대로 온전히 풀이 가능

5. **🔍 고해상도 시각자료 & 보기 이미지 완벽 지원**
   - 424개의 회로도, 파형도, 수식 이미지가 문제와 100% 매칭
   - 클릭 시 고해상도 확대 라이트박스 팝업 제공
   - 보기가 그림/수식인 문항은 모바일 친화적인 **2x2 그리드 레이아웃**으로 표시

6. **📱 PWA(Progressive Web App) & 완벽한 반응형**
   - `manifest.json` 및 `sw.js`(서비스 워커) 포함
   - 스마트폰에서 "홈 화면에 추가" 시 독립 앱(Standalone)처럼 전체 화면으로 구동

## 🚀 로컬 실행 방법

브라우저 보안 정책상 로컬 JSON 파일을 읽기 위해 로컬 HTTP 서버가 필요합니다.

### 방법 1. 파이썬 기본 웹 서버 (가장 간편)
터미널 또는 명령 프롬프트(CMD/PowerShell)에서 다음 명령어를 실행합니다:
```bash
python -m http.server 8080
```
그 후 브라우저 주소창에 `http://localhost:8080` 을 입력하여 접속합니다.

### 방법 2. VS Code Live Server 확장 프로그램
1. VS Code에서 본 프로젝트 폴더를 엽니다.
2. `Live Server` 확장을 설치한 후, `index.html` 우클릭 -> **"Open with Live Server"**를 누릅니다.

## 🌐 GitHub Pages 무료 배포 방법

정적 파일만으로 이루어져 있어 GitHub Pages를 통해 1분 만에 무료 배포할 수 있습니다.

1. **GitHub 저장소 생성**:
   - [GitHub](https://github.com)에서 새 Repository를 생성합니다 (예: `VibeCBT`).
2. **코드 푸시 (Git Push)**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: VibeCBT completed"
   git branch -M main
   git remote add origin https://github.com/<사용자아이디>/MeluCBT.git
   git push -u origin main
   ```
3. **GitHub Pages 활성화**:
   - 저장소 페이지 상단의 **Settings** 메뉴로 이동합니다.
   - 좌측 메뉴에서 **Pages**를 클릭합니다.
   - **Build and deployment > Branch** 항목에서 `main` 브랜치 / `/ (root)` 폴더를 선택하고 **Save**를 누릅니다.
4. **접속**:
   - 1~2분 후 생성되는 URL (`https://<사용자아이디>.github.io/MeluCBT/`)로 PC와 모바일 어디서나 접속하여 사용할 수 있습니다.

## 📱 스마트폰 홈 화면 앱 설치 (PWA)

- **iPhone / iPad (Safari)**:
  - 하단의 **공유 버튼(네모 위 화살표)** 클릭 -> **"홈 화면에 추가"** 선택
- **Android (Chrome)**:
  - 우측 상단 메뉴(점 3개) 클릭 -> **"앱 설치"** 또는 **"홈 화면에 추가"** 선택
- 이제 바탕화면의 앱 아이콘을 터치하면 상단 주소창 없이 앱처럼 깔끔하게 전체 화면으로 실행됩니다.
