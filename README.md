# 📡 MeluCBT - 정보통신기사 필기 기출문제 풀이 사이트

정보통신기사 필기 시험 준비용으로 직접 만든 개인 CBT 웹사이트입니다.  
매번 무거운 PDF나 문제집 들고 다니면서 채점하기 귀찮아서, PC나 스마트폰으로 출퇴근길에 편하게 기출문제 풀려고 제작했습니다.

로그인이나 데이터베이스 같은 번거로운 절차 없이, 링크만 누르면 바로 문제를 풀 수 있는 정적 웹사이트입니다.

👉 **웹사이트 바로가기**: [https://telecaster1265.github.io/MeluCBT/](https://telecaster1265.github.io/MeluCBT/)

---

## 💡 이런 점이 편합니다

- **회원가입/로그인 없음 & 광고 없음**
  - 접속하자마자 바로 문제 풀 수 있고, 모든 풀이 기록과 오답은 브라우저(`localStorage`)에만 안전하게 보관됩니다.
- **2016~2023년 총 2,300문제 수록**
  - 23회차 기출문제를 하나도 빠짐없이 싹 정리했습니다. 최근 5년(2019~2023) 기출만 모아서 집중 연습할 수도 있습니다.
- **회로도·도표 그림 100% 지원 (420여 장)**
  - 전자회로 특성상 그림 문제가 20% 가까이 되는데, 회로도나 파형이 깨지지 않게 깔끔하게 크롭해서 넣었습니다. 그림을 누르면 확대해서 볼 수 있습니다.
- **실전 150분 모의고사 & OMR 답안지**
  - 실제 시험처럼 100문제를 150분 시간 재면서 OMR에 마킹하듯 풀 수 있고, 제출하면 평균 60점 이상 및 40점 과락 여부를 자동으로 판정해 줍니다.
- **틀린 문제 자동 오답노트**
  - 풀다가 틀린 문제는 오답노트에 자동으로 쌓입니다. 나중에 오답만 쏙 골라서 재시험을 치를 수 있습니다.
- **핵심 해설 + 원클릭 검색 + 나만의 메모**
  - 각 문제별 핵심 공식과 풀이 이론이 들어있고, 다른 수험생들의 팁이 궁금할 땐 버튼 하나로 comcbt 해설 페이지나 구글 검색으로 바로 연결됩니다. 내가 외운 암기 팁도 직접 메모해둘 수 있습니다.

## 📱 폰에서 앱(App)처럼 쓰는 방법

스마트폰 브라우저로 접속한 뒤 홈 화면에 추가하면 상단 주소창 없이 네이티브 앱처럼 전체화면으로 쓸 수 있습니다. (PWA 지원)

- **아이폰 (Safari)**: 화면 하단 **공유 버튼(네모 위 화살표)** → **[홈 화면에 추가]**
- **갤럭시/안드로이드 (Chrome)**: 우측 상단 **메뉴(점 3개)** → **[홈 화면에 추가]** 또는 **[앱 설치]**
